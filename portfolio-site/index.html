C# Windows Forms | SQL Server LocalDB

Phumla Kamnandi Hotel Booking System

A desktop reservation system for hotel reception staff to make, modify, cancel, and enquire about guest bookings while maintaining room occupancy and deposit status.

View Features Technical Summary

Manage Booking

Implemented Use Cases

Make Booking

Checks room availability, validates guest details, calculates seasonal pricing, records deposits, and generates booking references.

Modify Booking

Searches by booking reference and updates existing booking dates and guest counts while protecting against overbooking.

Cancel Booking

Marks current bookings as cancelled and releases room availability for future enquiries.

Booking Enquiry

Displays booking reference, room, guest count, check-in/check-out dates, deposit amount, and confirmation status.

UX Improvements

  • Readable white controls across buttons, text boxes, and list boxes.
  • Return-to-home navigation on every workflow window.
  • All bookings list view for quick receptionist lookup.
  • Confirmation screen with send-email and print actions.

Validation

  • Check-out date must be after check-in date.
  • At least one adult is required.
  • Maximum of four guests per room.
  • Guest email, date of birth, address, and payment fields are validated before saving.

Technical Summary

Architecture: presentation, business, and data-access layers.

Database: SQL Server LocalDB with tables for rooms, guests, bookings, accounts, and seasons.

Business rules: seasonal rates, 10% deposit calculation, room capacity limits, and booking status tracking.

Project context: built from the Phumla Kamnandi Hotels case study requirements.
